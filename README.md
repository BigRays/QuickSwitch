# QuickSwitch — 文件对话框「快速切换」工具

复刻 Listary 标志性功能 **Quick Switch（快速切换）** 的独立实现（单文件源码，免安装 exe）。

在资源管理器里浏览过文件夹后，**任何程序的标准"打开/保存"文件对话框都会自动跳转到你最近访问的文件夹**——保存文件时再也不用一层层点文件夹，也无需按任何快捷键。

## 两种使用方式

**1. 自动切换（默认开启）**
- 像平常一样在资源管理器中浏览文件夹
- 打开任意程序的"另存为 / 打开"对话框（如记事本 Ctrl+S）→ 对话框**自动跳转**到你最近访问的文件夹
- 在对话框打开期间去资源管理器浏览了新文件夹？切回对话框时会**再次自动跳转**过去（与 Listary 行为一致）
- 仅当最近文件夹发生变化时才跳转：你手动导航过对话框再切回来，**不会**被打扰
- 不想要自动行为？托盘图标右键 → 取消勾选「自动切换到最近文件夹」

**2. 手动菜单（可选，用于切换到历史记录中的其他文件夹）**
- 在文件对话框中按 **Ctrl + `**（反引号，可自定义）→ 弹出最近文件夹菜单
- 鼠标或方向键 + 回车选择；悬停查看完整路径；也可「浏览其他文件夹…」
- 托盘图标右键 → 「设置快捷键…」直接按下新组合即可更换（即时生效）

所有提示（切换成功、不在对话框中、不支持的场景）都会以**屏幕上的深色气泡**显示，不依赖 Windows 通知设置。

## 排障：按了快捷键没反应？

1. 看屏幕弹出的深色气泡提示，它会说明具体原因：
   - 「前台窗口不是标准文件对话框：xxx」→ 焦点不在对话框上，先打开 打开/保存 对话框
   - 「未找到"文件名"输入框」→ 该程序使用自绘对话框（部分浏览器 / Qt 程序等），暂不受支持
   - 「未能切换到：xxx … 该程序以管理员身份运行」→ 见下条
2. 确认系统托盘（右下角，可能折叠在 ^ 中）有 QuickSwitch 图标；没有则重新运行 QuickSwitch.exe
3. 热键注册失败会弹窗提醒，此时换一个组合（托盘 → 设置快捷键…）
4. **目标程序以管理员身份运行**（如给 VS Code 设置过"以管理员身份运行"兼容属性）：Windows UIPI 安全机制会静默拦截普通权限进程的输入。托盘图标右键 → **「以管理员身份重启」**（UAC 点"是"），或勾选 **「始终以管理员身份运行」** 一劳永逸。新版会自动识别这种拦截并明确提示，不会假装切换成功。

所有"已切换"提示都经过回读校验：只有确认目标路径被对话框真正消费才提示成功，绝无"提示已切换但实际没跳"的情况。

## 工作原理

| 环节 | 实现方式 |
|------|----------|
| 记录最近文件夹 | `Shell.Application` COM（ShellWindows 集合）每 800ms 轮询所有资源管理器窗口的当前目录，路径变化即写入 MRU（支持多窗口/多标签） |
| 自动切换 | `SetWinEventHook` 监听 `EVENT_SYSTEM_FOREGROUND`：文件对话框获得焦点时，若"最近文件夹"较该对话框上次获焦时发生了变化，即自动切换（另有 800ms 轮询兜底；`EVENT_OBJECT_DESTROY` 清理对话框记录） |
| 切换文件夹 | 后台线程向"文件名"框 `EM_SETSEL + EM_REPLACESEL` 写入目标路径（等价用户全选粘贴，触发对话框编辑通知，兼容性最好），`WM_GETTEXT` 回读校验内容确为目标路径后才 `PostMessage` 模拟回车导航；利用文件对话框"输入文件夹路径并回车即跳转"的原生行为，对打开/保存对话框均有效且不会误关闭 |
| 对话框识别 | 类名 `#32770` + 子窗口特征校验（新式对话框含 `DirectUIHWND`，旧式含 `SysListView32`），避免误碰"运行"、打印设置等其他系统对话框 |

## 构建

- 运行 `build.cmd`（使用 Windows 自带的 .NET Framework 编译器 csc.exe，**无需安装任何开发工具**）
- 重新构建前先从托盘退出正在运行的实例（exe 被占用会编译失败）

## 配置文件 QuickSwitch.ini（与 exe 同目录，托盘菜单可图形化修改）

```ini
[Settings]
Modifiers=2      ; 修饰键：Ctrl=2 Alt=1 Shift=4 Win=8，可相加组合
Vk=192          ; 虚拟键码：A-Z=65-90，0-9=48-57，F1-F12=112-123，`=192
AutoSwitch=1    ; 自动切换：1=开启 0=关闭
AutoElevate=0   ; 始终以管理员身份运行：1=每次启动自动请求管理员权限 0=普通权限（默认）
```

手动修改 ini 后需重启 QuickSwitch；通过托盘菜单修改则即时生效。

## 已知限制

- 仅支持 **标准 Win32 通用文件对话框**（记事本、写字板、画图、VS Code、大部分 MFC/Delphi/WinForms 程序等）。自绘对话框（部分浏览器 / Qt 程序等）不受支持（按快捷键会明确提示）。
- 管理员权限程序的对话框受 Windows UIPI 限制：需 QuickSwitch 同样以管理员身份运行（托盘 →「以管理员身份重启」/「始终以管理员身份运行」，见排障第 4 条）。
- 与 Listary 原版差异：未实现对话框内按钮注入、收藏夹、项目规则等高级特性。
